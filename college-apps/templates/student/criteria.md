# List criteria — [Student Name]

What this student is actually looking for, as an explicit list. This is the college
list's version of an essay brief: it is written down, it changes as we talk, and it gets
re-read in full every time the list is built or rebalanced — so the list can't quietly
drift away from what the student said they wanted.

Every row carries a source tag: `[student YYYY-MM-DD]`, `[parent YYYY-MM-DD]`,
`[counselor YYYY-MM-DD]`, `[worksheet]`. When a student and a parent disagree, both rows
stay, both tagged. Never merge them into one invented compromise.

# College Applications

Eight skills that work through college applications the way a good high school counselor
would. Install from the [10xcolleges marketplace](https://github.com/tydev-new/10xcolleges).

| Skill | What it does |
|---|---|
| **college-app** | Front door — finds the student, works out what's next, routes to a specialist |
| **student-intake** | Reads the school packet, then interviews the student about goals and turn-offs |
| **college-list** | Safety / target / reach, tiered against this student's numbers and budget |
| **college-research** | A cited dossier per school: admit rate, real net price, program, honest fit |
| **essay-coach** | Rubric, angles, outline — then the student chooses how the first draft happens |
| **rec-request** | Per-teacher brag sheets with specific moments, and the ask itself |
| **app-tracker** | `tracker.xlsx` — deadlines plus a task list worked backwards from each one |
| **counselor-package** | Counselor-ready HTML/PDF, and the school's own packet as .docx |

Full documentation, including what the plugin refuses to do and where its numbers come
from, is in the [repository README](https://github.com/tydev-new/10xcolleges#readme).

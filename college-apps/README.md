# College Applications

Eight skills that work through college applications the way a good high school counselor
would. ✅ marks the first wave — built, reviewed, and measured; the others work but aren't
through that process yet. Install from the [10xcolleges marketplace](https://github.com/tydev-new/10xcolleges).

| Skill | What it does |
|---|---|
| **college-app** | Front door — finds the student, works out what's next, hands off to a specialist |
| **student-intake** ✅ | Sets up the folder, reads the packet, then interviews the student — every line in their words, tagged with its source, until the list has what it needs |
| **college-list** | Safety / target / reach, tiered against this student's numbers and budget |
| **college-research** | A report per school, with sources: admit rate, real net price, program, honest fit |
| **essay-coach** ✅ | One essay at a time: a brief (rubric from the college's guidance), angles, then scored reviews draft by draft — never written for the student |
| **rec-request** | Per-teacher brag sheets with specific moments, and the ask itself |
| **app-tracker** | `tracker.xlsx` — deadlines plus a task list worked backwards from each one |
| **counselor-package** | Counselor-ready HTML/PDF, and the school's own packet as .docx |

Full documentation, including what the plugin refuses to do and where its numbers come
from, is in the [repository README](https://github.com/tydev-new/10xcolleges#readme).
